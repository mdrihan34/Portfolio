# 🌐 Personal Portfolio Website — [Rihan](https://rihan-dev.vercel.app)

Welcome to my **personal portfolio** project! This is a full-stack web application where I can **showcase my projects**, manage them through a **dashboard**, and **receive messages** via a contact form. Built with **React**, **Tailwind CSS**, and a **Node.js + Express + MongoDB backend**, this site is secure, fully responsive, and easy to deploy.



---![Screenshot 2025-04-09 232239](https://github.com/user-attachments/assets/71d0f642-129f-4c97-ab7e-5b9432d163a1)


## 🔥 Features

- 🧑‍💻 Personal portfolio website
- 🗂️ **Add / Edit / Delete Projects** via secure Dashboard
- 📥 View **messages** from the contact form
- 📄 Upload and control **resume download link**
- 🔐 Password-protected **Dashboard** (password stored in `.env`)
- 📱 Fully **responsive** design
- ✨ Beautiful **animations**
- 🧩 Built with **React Router**, **TailwindCSS**, and full **Node.js/Express backend**
- 🚀 Live site: [rihan-dev.vercel.app](https://rihan-dev.vercel.app)

---

## 🛠 Tech Stack

**Frontend:**
- React
- React Router
- Tailwind CSS
- Framer Motion (for animations)

**Backend:**
- Node.js
- Express
- MongoDB
- dotenv
